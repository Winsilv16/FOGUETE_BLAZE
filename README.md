# Foguete Blaze🚀

## Sobre o projeto

**Foguete Blaze** é um jogo 2D desenvolvido em Python utilizando a biblioteca **Pygame**.
O jogador controla uma nave espacial e deve **desviar de asteroides**, **derrotar inimigos** e **sobreviver o máximo possível** para alcançar a maior pontuação.

---

## Funcionalidades

* Controle da nave com teclado
* Sistema de tiros
* Asteroides com movimento aleatório
* Inimigos (monstros) com vida
* Chefes (bosses) com mais dificuldade
* Sistema de pontuação
* Recorde salvo em arquivo
* Menu inicial e seleção de dificuldade

---

## 🕹️Controles

| Tecla   | Ação                  |
| ------- | --------------------- |
| ⬅️ / ➡️ | Movimentar nave       |
| ESPAÇO  | Atirar                |
| ESC     | Voltar ao menu / sair |

## Como executar

1. Clone o repositório:

```bash
git clone <seu-repositorio>
```

2. Acesse a pasta:

```bash
cd FG
```

3. Crie um ambiente virtual (opcional, recomendado):

```bash
python -m venv venv
source venv/bin/activate  # Linux / Codespaces
```

4. Instale o Pygame:

```bash
pip install pygame
```

5. Execute o jogo:

```bash
python jogar.py
```

---

## ⚠️Observações!!!

* Certifique-se de que todas as imagens estejam na pasta correta
* O arquivo `recorde.txt` é usado para salvar a maior pontuação
* O jogo pode não rodar em ambientes sem suporte gráfico (ex: Codespaces sem interface)
